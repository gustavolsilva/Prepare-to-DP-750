## Tarefa 1: Acessar o Workspace no Azure Portal e Navegar até Compute

1. Acesse o portal do Azure (https://portal.azure.com).
2. Localize seu recurso 'Azure Databricks Service' e clique em 'Launch Workspace'.
3. Na barra de navegação esquerda do Databricks, clique no ícone 'Compute' (Computação).
4. Observe as abas disponíveis: 'All-Purpose Compute', 'Job Clusters', 'Serverless' e 'Pools'.

## Tarefa 2: Criar um Cluster All-Purpose Otimizado para FinOps

1. Clique no botão 'Create compute' no canto superior direito.
2. Configure os parâmetros exatos:
   - Compute name: dp750-dev-cluster
   - Policy: Personal Compute ou Unrestricted
   - Multi node / Single node: Selecione 'Single node' (para economizar custos de VM em laboratório)
   - Databricks Runtime Version: 15.4 LTS (Scala 2.12, Spark 3.5.0)
   - Node type: Standard_D4ds_v5 (4 vCPUs, 16 GB memória)
   - Auto-termination: Habilite a caixa e defina rigorosamente para 20 minutes (regras de FinOps do exame).
3. Clique em 'Create compute' e aguarde o status mudar de 'Pending' para 'Running' (círculo verde).

## Tarefa 3: Criar um Notebook Databricks e Testar Métricas de FinOps com PySpark

1. No menu lateral esquerdo, clique em 'Workspace' > 'Users' > Seu Usuário e clique em 'Create' > 'Notebook'.
2. Nomeie o notebook como 'lab_0001_finops_compute'.
3. Conecte o notebook ao cluster 'dp750-dev-cluster' no seletor superior direito.
4. Na Célula 1, digite o código PySpark abaixo e pressione Shift + Enter para executar:

```python
# COMMAND ----------
# Célula 1: Identificação da sessão Spark e cálculo de consumo de DBUs
spark_version = spark.conf.get("spark.databricks.clusterUsageTags.sparkVersion")
cluster_id = spark.conf.get("spark.databricks.clusterUsageTags.clusterId")
print(f"✓ Sessão Spark Ativa! Cluster ID: {cluster_id} | DBR Version: {spark_version}")

# Simulação FinOps de consumo de DBUs:
def calcular_custo_pipeline(horas_execucao, dbu_por_hora, preco_dbu=0.55):
    dbus_totais = horas_execucao * dbu_por_hora
    custo_total = dbus_totais * preco_dbu
    return dbus_totais, custo_total

# Cenário 1: All-Purpose Cluster (Interativo - taxa elevada)
dbu_ap, custo_ap = calcular_custo_pipeline(horas_execucao=5, dbu_por_hora=3.0, preco_dbu=0.55)

# Cenário 2: Job Cluster Efêmero (Produção - taxa reduzida em até 60%)
dbu_job, custo_job = calcular_custo_pipeline(horas_execucao=5, dbu_por_hora=1.5, preco_dbu=0.40)

print(f"📊 Relatório Comparativo FinOps (5 horas de workload):")
print(f"   [All-Purpose] DBUs: {dbu_ap:.1f} | Custo: ${custo_ap:.2f} USD")
print(f"   [Job Cluster] DBUs: {dbu_job:.1f} | Custo: ${custo_job:.2f} USD")
print(f"   💡 Economia obtida com Job Cluster: ${custo_ap - custo_job:.2f} USD ({(1 - custo_job/custo_ap)*100:.1f}%)")
```

**Saída Esperada:**
```text
✓ Sessão Spark Ativa!
📊 Relatório Comparativo FinOps (5 horas de workload):
   [All-Purpose] DBUs: 15.0 | Custo: $8.25 USD
   [Job Cluster] DBUs: 7.5 | Custo: $3.00 USD
   💡 Economia obtida com Job Cluster: $5.25 USD (63.6%)
```
