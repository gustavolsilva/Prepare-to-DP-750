# Lab 0006: Integração Segura com Azure Key Vault e Storage Credentials ADLS Gen2

> **⚠️ PRÉ-REQUISITO OBRIGATÓRIO DA AZURE (Microsoft Learn Standards):**
> Para realizar este laboratório prático, **você precisará de um Workspace do Azure Databricks alocado na sua assinatura do Microsoft Azure** (Recomendado tier Premium para suporte a Unity Catalog e Serverless Compute).
> **Pré-requisitos Técnicos:** Assinatura Azure com Azure Key Vault e Azure Data Lake Storage Gen2 provisionados.

- **Duração Estimada:** 35 minutos
- **Cenário:** A equipe de arquitetura proibiu credenciais em texto plano. Você deve conectar o Databricks ao Azure Key Vault via Secret Scope e configurar Storage Credentials no Unity Catalog via Managed Identity para acessar o ADLS Gen2.

---

## Tarefa 1: Obter os Dados do Azure Key Vault

1. No Azure Portal, abra o recurso Azure Key Vault.
2. Na aba 'Properties', copie:
   - DNS Name (ex: `https://kv-dp750-prod.vault.azure.net/`)
   - Resource ID (ex: `/subscriptions/.../resourceGroups/.../providers/Microsoft.KeyVault/vaults/...`)
3. Na aba 'Secrets', crie um segredo chamado `adls-access-token` com um valor de teste.

---

## Tarefa 2: Criar o Secret Scope Backed pelo Azure Key Vault no Databricks

1. No navegador, acerte a URL do seu workspace Databricks adicionando `#secrets/createScope` ao final:
   `https://<sua-instancia-databricks>#secrets/createScope`
2. Preencha os campos:
   - Scope Name: `kv-dp750-scope`
   - Manage Principal: Creator
   - DNS Name: cole o DNS Name do Key Vault
   - Resource ID: cole o Resource ID do Key Vault
3. Clique em 'Create'.

---

## Tarefa 3: Recuperar o Segredo Mascarado via PySpark

1. Abra um notebook e execute o código de leitura do segredo:

```python
# COMMAND ----------
# Leitura segura do segredo armazenado no Azure Key Vault
token = dbutils.secrets.get(scope="kv-dp750-scope", key="adls-access-token")

# O Databricks mascara automaticamente o valor na saída com [REDACTED]
print(f"Segredo recuperado com segurança: {token}")

# Valida que o token não está vazio
assert len(token) > 0, "Falha ao recuperar o token do Azure Key Vault"
print("✓ Validação de conformidade DP-750 aprovada: Token protegido!")
```

**Saída Esperada:**
```text

✓ Validação de conformidade DP-750 aprovada: Token protegido!
```
