# Lab 0005: Governança de FinOps: Cluster Policies e Serverless SQL Warehouses

> **⚠️ PRÉ-REQUISITO OBRIGATÓRIO DA AZURE (Microsoft Learn Standards):**
> Para realizar este laboratório prático, **você precisará de um Workspace do Azure Databricks alocado na sua assinatura do Microsoft Azure** (Recomendado tier Premium para suporte a Unity Catalog e Serverless Compute).
> **Pré-requisitos Técnicos:** Azure Databricks Workspace Premium com permissão de criação de Cluster Policies e SQL Warehouses.

- **Duração Estimada:** 35 minutos
- **Cenário:** Implementar uma política de computação corporativa que force autotermination rígido de 20 minutos, proíba VMs de alto custo e configurar um Serverless SQL Warehouse com auto-stop de 1 minuto para o time de Analytics.

---

## Tarefa 1: Criar uma Cluster Policy Restritiva em JSON

1. No workspace Databricks, vá em 'Compute' > aba 'Cluster policies' > 'Create policy'.
2. Nome da política: `DP750-Strict-FinOps`.
3. Cole o JSON de governança abaixo no editor:

```python
{
  "autotermination_minutes": {
    "type": "range",
    "maxValue": 20,
    "defaultValue": 15,
    "isOptional": false
  },
  "node_type_id": {
    "type": "allowlist",
    "values": [
      "Standard_D4ds_v5",
      "Standard_D8ds_v5"
    ],
    "defaultValue": "Standard_D4ds_v5"
  },
  "custom_tags.CostCenter": {
    "type": "fixed",
    "value": "DataEngineering-DP750"
  }
}
```

**Saída Esperada:**
```text
✓ Política DP750-Strict-FinOps criada com sucesso com limites rígidos de FinOps.
```

---

## Tarefa 2: Conceder Permissão de Uso na Política

1. Na aba 'Permissions' da política recém-criada, adicione o grupo `users` com o privilégio `CAN_USE`.
2. Tente criar um cluster como usuário comum usando esta política e verifique que o autotermination não pode ultrapassar 20 minutos e instâncias com GPU estão bloqueadas.

---

## Tarefa 3: Provisionar um Serverless SQL Warehouse

1. No menu lateral, alterne a persona para 'SQL' ou clique em 'SQL Warehouses'.
2. Clique em 'Create SQL Warehouse'.
3. Configure:
   - Name: `dp750-serverless-bi`
   - Cluster size: 2X-Small
   - Type: Serverless
   - Auto stop: 1 minute (desligamento ultrarrápido após inatividade)
   - Scaling: Min 1, Max 2 clusters.
4. Clique em 'Create' e execute uma query de teste no SQL Editor (`SELECT current_timestamp();`).
5. Verifique que o startup levou menos de 10 segundos!
