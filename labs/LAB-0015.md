# Lab 0015: Orquestração em Produção: Databricks Workflows, DABs e Spark UI

> **⚠️ PRÉ-REQUISITO OBRIGATÓRIO DA AZURE (Microsoft Learn Standards):**
> Para realizar este laboratório prático, **você precisará de um Workspace do Azure Databricks alocado na sua assinatura do Microsoft Azure** (Recomendado tier Premium para suporte a Unity Catalog e Serverless Compute).
> **Pré-requisitos Técnicos:** Azure Databricks Workspace com acesso a Workflows e Databricks CLI configurada localmente.

- **Duração Estimada:** 45 minutos
- **Cenário:** Orquestrar um pipeline multitarefa no Databricks Workflows, utilizar Task Values, simular falha e executar Repair Run, além de validar o manifesto de Databricks Asset Bundles (databricks.yml).

---

## Tarefa 1: Criar um Job Multitarefa no Databricks Workflows

1. No menu esquerdo, clique em 'Workflows' > 'Jobs' > 'Create job'.
2. Configure a Tarefa 1:
   - Task name: `01_bronze_ingestion`
   - Type: Notebook
   - Compute: New Job Cluster (Standard_D4ds_v5)
3. Clique no botão '+' abaixo da Tarefa 1 para adicionar a Tarefa 2:
   - Task name: `02_silver_transform`
   - Depends on: `01_bronze_ingestion`
4. Salve o Job com o nome `DP750-Production-Orchestrator`.

---

## Tarefa 2: Utilizar Task Values para Passagem de Parâmetros

1. Na Tarefa 1, insira o código PySpark para exportar o ID do lote:
   `dbutils.jobs.taskValues.set(key="batch_run_id", value="LOTE_2025_001")`
2. Na Tarefa 2, insira o código para consumir o valor:
   `lote = dbutils.jobs.taskValues.get(taskKey="01_bronze_ingestion", key="batch_run_id")`
   `print(f'Processando lote: {lote}')`

---

## Tarefa 3: Simular Falha e Executar o Recurso 'Repair Run'

1. Adicione um comando proposital de erro na Tarefa 2 (`raise ValueError('Erro temporário de conexão')`).
2. Clique em 'Run now'. O job executará a Tarefa 1 com sucesso e falhará na Tarefa 2.
3. Corrija o erro no notebook da Tarefa 2.
4. Na tela de execução do Job, clique no botão 'Repair run'. Observe que a Tarefa 1 NÃO É REEXECUTADA, poupando tempo e DBUs, executando exclusivamente a Tarefa 2 que havia falhado!

---

## Tarefa 4: Validar Manifesto de Databricks Asset Bundles (databricks.yml)

1. Em seu terminal local, crie o arquivo `databricks.yml` e valide a sintaxe oficial:
   `databricks bundle validate`
2. Observe a saída confirmando que os recursos de jobs e pipelines estão sintaticamente corretos para deploy via CI/CD no Azure DevOps ou GitHub Actions.
